# もふスタ100日 制作ボード

100日チャレンジの動画コンテンツ制作進捗を管理するWebアプリ。

## 公開URL

https://mofuapp.github.io/mofu-100days/

## 機能

- 100日分のタイトル・内容一覧
- 制作ステップ管理（台本 → 収録 → 編集 → MOSH公開）
- Phase別進捗・全体進捗リング
- スマホ対応（PWA・ホーム画面追加可）
- データは端末内（localStorage）に保存

## スマホで使う

1. 上記URLをSafari/Chromeで開く
2. 「ホーム画面に追加」でアプリ化

※ もふ日記とは別アプリです。
